# Implementation notes: implement-outstanding-issues

## 2026-07-23

- Coordinated all five open Cairn todos in one change because shader, avatar, demo, motion, and speech integration overlap.
- `kokoro-js` 1.2.1 does not expose per-phoneme timestamps. It exposes phoneme strings with generated audio chunks. The adapter will distribute phoneme events over each measured chunk duration and will document the timing as derived, not exact provider alignment.
- Background themes, opaque core, day/night look, and caruncle size remain lab-only prototypes. Production defaults do not change for those unapproved controls.
- Tongue articulation will use committed sparse authored source-vertex corrections consumed by the deterministic build pipeline. Runtime procedural displacement remains rejected.
- Blender 4.5.12 hung during dynamic-loader initialisation on this Darwin build. Blender 4.2.10 LTS from the official mounted image completed deterministic headless authoring and geometry verification.
- Seven separate feature buffers combined with the mesh's existing vertex buffers exceeded WebGPU's eight-buffer binding limit and rendered a blank canvas. The seven logical feature attributes now share two interleaved buffers. A live WebGPU smoke showed no pipeline warnings and a non-empty render.
- `kokoro-js` 1.2.1's `stream(string)` yields generated audio but never closes its internal splitter. The adapter now constructs `TextSplitterStream`, pushes the text, closes it, then consumes the finite stream. A cold real-model browser smoke fetched only after the button gesture and emitted canonical visemes during playback.
- The old whole-head ghosting metric was not diagnostic under the new owner look. A same-look smoke now derives an on-mesh equal-axis blend mask, uses a sparse marker texture and a low threshold that retains half-bright legacy copies, then compares the old and new paths. Interpolated single-sample ghosting measured 0.0942 versus 0.0992 for legacy blending while retaining 99.1 percent of localized coverage.
- The visual baseline was recalibrated once against the owner-approved production look. The ordinary score passes and the smeared/duplicated negative control still fails every protected dimension.
- Owner selected the conservative background path after reviewing the completed gate: keep background themes, opaque core, and day/night controls lab-only; preserve current library defaults.
- Linux CI measured the duplicated 45-degree negative control at 1.377 times baseline, below the prior 1.4 fail boundary while the ordinary view remained at 0.873 times baseline. Tightening only the ghosting fail boundary to 1.33 restores cross-platform harness protection without changing the ordinary pass boundary or production rendering.
- Independent review found that the assetless placeholder bypassed `buildLoadedAvatar`, so its geometry lacked the seven attributes read by the production skin graph. `createPlaceholderAvatar` now runs the same feature-mask baker, and the built-package consumer smoke covers both default and placeholder paths.
- Independent review found that the default Kokoro scheduler cancelled frame ID zero rather than the actual pending request. It now tracks and cancels the concrete ID and avoids rescheduling when cleanup happens inside a callback.
- Independent review found that the lab cached the final HQ viseme after cancellation or terminal completion. All adapter switches and terminal paths now clear cached weights; the browser smoke waits until both viseme and tongue morphs return to neutral.
- Automated PR review prompted a second hardening pass: Kokoro is now an optional peer and core imports only the base speech implementations, so the default bundle contains no Kokoro symbols while `dist/speech.js` retains the adapter.
- Normalised head configurations are deeply frozen at runtime and recursively readonly in TypeScript. Material dispose events unregister VFX bindings, preventing repeated avatar replacement from retaining old text-skin engines.
- Direct overlapping Kokoro utterances now cancel and clean the previous handle. Browser smokes require every claimed lab control, cover both day and night, close on failures, and verify a real model without bypassing autoplay policy.
- Tongue provenance now points at the verified sparse manifest, records the portable Blender command, source licence, input hashes, and final GLB hash. The asset test checks that the authored pose recipe matches every embedded manifest source.
- `kokoro-js` 1.2.1 can synchronously loop in `TextSplitterStream` when an at-mention or URL is followed immediately by a newline. The adapter now removes caller-supplied line boundaries before either the explicit or package-internal splitter receives text; a regression test pins both vulnerable token forms.
